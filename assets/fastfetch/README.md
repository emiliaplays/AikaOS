# Aika Fastfetch configurations

`config.jsonc` is the supplied color portrait used as the live-session default. `config-compact.jsonc` and `config-full.jsonc` provide alternative layouts. Logos are embedded as ASCII plus ANSI truecolor sequences; no image-display protocol or Nerd Font is required.

Run `fastfetch --config ./config.jsonc`. Enlarge the terminal for the full portrait. Plain and raw-color text versions are included for reuse in a configuration. See `ARTWORK.md` for provenance and licensing scope.
